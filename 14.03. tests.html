MCQ — choose onesection 4.1.22. Which Windows log channel contains the audit records (logons, privilege use, account changes) and is written only by the Local Security Authority?
  • Application receives events from installed programs.
  • Correct: the Security log is the audit log; only LSASS writes to it.
  • System receives events from Windows components, drivers and services.
  • Setup records installation and update events.
Hint: Audit Success / Audit Failure are the keywords of this channel.

MCQ — choose onesection 4.1.37. In the rsyslog rule auth,authpriv.* /var/log/auth.log the ".*" means:
  • Correct: facility.severity — the star selects every severity from emerg to debug.
  • The facilities are written before the dot (auth and authpriv).
  • A single severity would be written by name, e.g. auth.debug.
  • The rule names one destination file.
Hint: The syntax is facility.severity → destination.
MCQ — choose onesection 4.1.38. What is the PRI value of a kernel (facility 0) emergency (severity 0) message?
  • Correct: PRI = facility × 8 + severity = 0 × 8 + 0 = 0.
  • 8 would be facility 1 (user), severity 0.
  • 7 is the severity "debug", not a PRI of this message.
  • 56 would be facility 7 (news), severity 0.
Hint: PRI = facility × 8 + severity.

MCQ — choose onesection 4.2.212. Which is the best way to capture all the traffic of a server on a switched LAN without installing anything on the server?

  • Logs are host evidence, not network traffic.

MCQ — choose onesection 4.2.213. Which tool is the command-line twin of Wireshark, used to export chosen fields of a capture to a CSV file?
  • tcpdump captures and prints packets but has no field export to CSV.
  • Correct: tshark -T fields -e … writes selected fields, one line per frame.
  • Npcap is the capture driver on Windows.
  • Pktmon is the built-in Windows capture tool; it converts to pcapng, not to CSV.
Hint: It is part of the Wireshark package and its name starts with a "t".
MCQ — choose onesection 4.2.114. A client sends a SYN to port 23 of a server and receives a packet with the RST flag. What does it mean?

  • Correct: RST in answer to a SYN means nothing listens on that port.
  • A drop produces no answer at all.
  • A normal end uses FIN.
Hint: Three outcomes of a SYN: SYN-ACK, RST, or silence.
